# Проверка визуализации комнаты

Два инструмента. Оба запускаются из корня проекта и ничего не меняют в рабочей базе.

## Настоящая модель: работает ли ключ и как рисует

```
node --env-file=.env tools/render-check/check.cjs кадр.jpg
node --env-file=.env tools/render-check/check.cjs кадр.jpg --anchor готовая.jpg --ref диван.jpg --evening --out результат.jpg
node --env-file=.env tools/render-check/check.cjs кадр.jpg --dump        # показать текст запроса, ничего не отправляя
```

Без сервера и браузера: кадр из файла уходит модели теми же функциями, что на сервере (`server/core/imagegen.js`,
`server/core/renders.js`), картинка пишется рядом с кадром. Печатается время ответа и расход токенов.
Каждый запуск — платное обращение к модели.

- Кадр берётся из редактора: запустите сервер с `RENDER_MOCK=1`, создайте визуализацию и нажмите «Скачать» —
  на заглушке «визуализацией» становится сам кадр, то есть ровно то, что получает модель.
- `--anchor` — готовая визуализация этой же комнаты: новый кадр рисуется в её стиле. `--ref` — фото товаров из каталога.
- Сравнить модели на одном кадре: `RENDER_MODEL=gemini-3-pro-image node --env-file=.env tools/render-check/check.cjs кадр.jpg`
  (имя модели попадает в имя файла результата).
- Если ответ идёт дольше 45 секунд, на Vercel он может не уложиться во время жизни функции: поставьте `RENDER_THINKING=minimal`
  или увеличьте `maxDuration` в `vercel.json` вместе с `RENDER_TIMEOUT_MS`.

На что смотреть в результате: мебель осталась той же (форма, цвет, место), стены и проёмы на месте, ничего лишнего не появилось.

## Браузер на заглушке: весь путь пользователя

```
node tools/render-check/e2e.cjs
```

Поднимает сервер на временной папке с `RENDER_MOCK=1` и проходит путь в Chromium: комната с мебелью → 3D → «Визуализация» →
ракурсы → первая картинка → ещё ракурс в том же стиле → удаление → смета → просмотр по ссылке владельца.
Нужен пакет `playwright` и Chromium — как для `tools/ai-eval/e2e.cjs` (`PLAYWRIGHT_PATH` — путь к уже установленному пакету).
Снимки экрана и `frame.jpg` (кадр, который уходит модели) складываются в `tools/render-check/shots` (`E2E_SHOTS` — другая папка).
