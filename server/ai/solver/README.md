# Солвер расстановки (И1)

Код, который превращает замысел в конкретные позы и товары и гарантирует жёсткие правила (ТЗ §19–20). Работает без сети и без языковой модели.

## Модули

| Файл | Что делает |
| --- | --- |
| `public/shared/ai-room.js` | Геометрия помещения (§13): стены с внутренними нормалями, углы, вход, зоны, области, оси, сетка 50 мм, поле расстояний, проходы |
| `public/shared/ai-knowledge/*.js` | База знаний (§14, прил. А): категории и права, способы постановки, зоны обслуживания, группы, программы комнат, справочники |
| `public/shared/ai-rules.js` | Правила (§15, §20): Ж1–Ж14, унаследованные нарушения (§11.8), инварианты прав (§11.7), точка привязки (§11.4), М1–М10 и М16, оценка 0–100 |
| `public/shared/ai-relations.js` | Словарь отношений (§18.6): оценка 0–1 и кандидатные позы от партнёра |
| `server/ai/solver/index.js` | `prepare` (общее для запуска) и `solveConcept` (замысел → до 3 решений + диагностика) |
| `server/ai/solver/candidates.js` | Кандидатные позиции по способу постановки (§19.2) |
| `server/ai/solver/products.js` | Кандидаты товаров (§17.1, §17.3; в И2 добавится оценка стиля и цены) |
| `server/ai/solver/rng.js` | Детерминированный генератор (§19.6) |
| `server/ai/solver/svg.js`, `cli.js` | Картинки решений и офлайн-запуск |

Модули `public/shared` — общие для браузера и Node, как `catalog-types.js`: в редакторе подключаются в порядке catalog-types → geometry → ai-knowledge/* → ai-room → ai-rules → ai-relations.

## Поиск

1. Порядок: якоря → зависимые → дополнения; настенные и «на основании» — после напольных; члены группы (тумбы, стулья, столик) идут сразу за своим якорем.
2. Лучевой поиск: ширина 24, по 12 лучших поз на состояние; не больше 4 состояний с одинаковой позой первого якоря.
3. Каждая поза проверяется на Ж1–Ж10 против комнаты и неподвижных (кешируется) и против уже поставленного; доступность (Ж11) — лениво, только для состояний, попадающих в луч.
4. Якорь группы заглядывает вперёд: поместятся ли его стулья, тумбы, столик.
5. Нет ни одной позы — лестница ослаблений §19.4: `nice` → `should` → подсказки → все способы постановки → все товары → убрать необязательное добавление → диагностика.
6. Готовые расстановки проходят полную проверку `ai-rules.validate`, оценку и локальное улучшение.

Настройки (`prepare(..., limits)`): `beam`, `branch`, `sameFirst`, `maxExpansions`, `timeMs`, `wallStep` (50 мм; в комнатах с периметром больше 24 м — 100 мм), `mountStep`, `freeMaxPoints`, `products`, `improveTrials`, `accessPages`.

## Запуск

```sh
npm run solve -- living-4x5 --out /tmp/svg --soft   # одна фикстура, картинки и мягкие правила
npm run solve -- all --out /tmp/svg                 # весь эталонный набор
npm test                                            # автотесты А1–А5, А10 и модульные
```

Фикстуры — `test/ai/fixtures/index.js` (42 комнаты §28.1 с ручными замыслами), каталог — фиксированный `test/ai/fixtures/catalog.json`.
